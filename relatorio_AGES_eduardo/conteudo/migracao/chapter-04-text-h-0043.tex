\subsection*{4.2.2 Banco de dados utilizado}
\label{ages-ii:text-h-0043}
\addcontentsline{toc}{subsection}{4.2.2 Banco de dados utilizado}

\indent O banco de dados utilizado é do tipo relacional com base em um modelo do Postgresql. Também foi utilizado o SQLAlchemy como ferramenta de ORM para facilitar o mapeamento das entidades. Essa combinação oferece um ambiente robusto e eficiente para o armazenamento e gerenciamento de dados.\par
