\subsection*{3.2.2 Banco de dados utilizado}
\label{ages-ii:text-h-0043}
\addcontentsline{toc}{subsection}{3.2.2 Banco de dados utilizado}

\indent O banco de dados utilizado é do tipo relacional com base em um modelo do Postgresql\space\cite{ages-ii-postgresql}. Também foi utilizado o SQLAlchemy\space\cite{ages-ii-sqlalchemy} como ferramenta de ORM para facilitar o mapeamento das entidades. Essa combinação oferece um ambiente robusto e eficiente para o armazenamento e gerenciamento de dados.\par

\indent Mais detalhes podem ser encontrados aqui: \href{https://tools.ages.pucrs.br/industria-digital/wiki/-/wikis/Banco\%20de\%20dados}{Banco de Dados}\par
