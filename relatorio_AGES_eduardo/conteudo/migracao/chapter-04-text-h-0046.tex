\indent Angular (com TypeScript):\space\cite{ages-ii-angular}\space\cite{ages-ii-typescript}
Utilizado para o Front-end da aplicação, desenvolvido em TypeScript\space\cite{ages-ii-typescript}, responsável por renderizar a interface de usuário, que inclui a \textit{landing page}, a tela de \textit{dashboards}, a visualização de mapa e a página das empresas. Angular\space\cite{ages-ii-angular} envia requisições HTTP\space\cite{ages-ii-http-rfc9110} para o Back-end e recebe dados em formato JSON\space\cite{ages-ii-json-rfc8259}, atualizando a interface do usuário em tempo real.
\originaltab{}\href{https://v17.angular.io/docs}{Documentação Angular}\originalinlinetab{}%
\originaltab{}\href{https://www.typescriptlang.org/pt/docs/handbook/typescript-in-5-minutes.html}{Documentação TypeScript}
Python:\originalspace{}\cite{ages-ii-python}
Utilizado no Back-end para realizar as requisições web à Graph API\space\cite{ages-ii-graph-api}, obtendo dados de usuários das redes sociais. Python\space\cite{ages-ii-python} também é responsável pela criação de lógicas de enriquecimento de dados, pelo algoritmo de presença digital e pela comunicação com o Front-end via FastAPI\space\cite{ages-ii-fastapi}.
\originaltab{}\originaltab{}\href{https://docs.python.org/pt-br/3/}{Documentação Python}
FastAPI:\originalspace{}\cite{ages-ii-fastapi}
Utilizado para construir a API que serve como interface de comunicação entre o Front-end Angular\space\cite{ages-ii-angular} e o banco de dados PostgreSQL\space\cite{ages-ii-postgresql}, gerenciando a lógica de negócios e facilitando a troca de dados entre os componentes do sistema.
\originaltab{}\originaltab{}\href{https://fastapi.tiangolo.com/}{Documentação FastAPI}
Graph API:\space\cite{ages-ii-graph-api}
Utilizada para fazer requisições e obter dados de perfis de usuários nas redes sociais, que são integrados ao sistema e utilizados no enriquecimento de dados e no cálculo de presença digital.
\href{https://developers.facebook.com/docs/graph-api/guides/explorer/}{Documentação Graph API}
SQLAlchemy:\space\cite{ages-ii-sqlalchemy}
Utilizado como ORM (\textit{Object-Relational Mapping}), facilitando o mapeamento entre as entidades do sistema e as tabelas no banco de dados PostgreSQL\space\cite{ages-ii-postgresql}, simplificando a manipulação de dados e consultas via Python\space\cite{ages-ii-python}.
\originaltab{}\href{https://docs.sqlalchemy.org/en/20/}{Documentação SQLAlchemy}
PostgreSQL:\originalspace{}\cite{ages-ii-postgresql}
Banco de dados relacional utilizado para armazenar as informações das empresas presentes no banco de dados da Receita Federal, bem como os dados capturados dos perfis das redes sociais. As consultas são feitas via FastAPI\space\cite{ages-ii-fastapi} e SQLAlchemy\space\cite{ages-ii-sqlalchemy} para obter os dados necessários.
\href{https://www.postgresql.org/docs/}{Documentação PostgreSQL}
Docker\space\cite{ages-ii-docker}
Utilizado para criar ambientes de testes locais, especialmente para o banco de dados PostgreSQL\space\cite{ages-ii-postgresql}, garantindo a consistência e confiabilidade dos testes em desenvolvimento.
\href{https://www.docker.com/}{Documentação Docker}
Essas tecnologias foram integradas com o objetivo de oferecer uma experiência completa e otimizada para os usuários finais. Com isso, é possível pesquisar empresas com base em seu CNAE (Classificação Nacional de Atividades Econômicas) e/ou região geográfica, obtendo como resultado um mapa interativo com a localização dessas empresas. Além disso, o sistema retorna informações valiosas, como dados de redes sociais, informações de contato e \textit{dashboards} detalhados sobre a presença digital de cada empresa encontrada, incluindo níveis de visibilidade e engajamento online. Tudo isso facilita o acesso a dados essenciais para tomadas de decisão.
