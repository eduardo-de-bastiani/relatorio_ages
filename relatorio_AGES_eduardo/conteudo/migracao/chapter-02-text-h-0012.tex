\subsection{Tecnologias utilizadas}
\label{ages-i:text-h-0012}

\noindent \originaltab{}Para o desenvolvimento do projeto, utilizamos as seguintes tecnologias:\par

\begin{itemize}
\item \noindent \underline{TypeScript:}\textbf{\originalspace{}}\par

\noindent Utilizado para desenvolver as telas do tablet, utilizando componentes do React. A tipagem estática do TypeScript proporcionou maior segurança e facilidade na manutenção do código Front-end.\par

\noindent Também foi utilizado para desenvolver a lógica de negócios, APIs e integrações necessárias para o funcionamento do sistema. O TypeScript trouxe a mesma segurança e facilidade de manutenção para o código do servidor.\par

\noindent \href{https://www.typescriptlang.org/docs/}{\underline{Documentação TypeScript}}\par

\item \noindent React:\originalspace{}\par

\noindent Utilizado para criar a interface do usuário no tablet, permitindo a interação com o fluxograma para descobrir os melhores suplementos.\par

\noindent Também foi utilizado para criar as interfaces web acessíveis pelo lojista e pelo administrador, com layouts similares e funcionalidades específicas para cada tipo de usuário.\par

\noindent \href{https://react.dev/}{\underline{Documentação React}}\par

\item \noindent Node.js:\originalspace{}\par

\noindent Utilizado para criar as APIs RESTful que permitem a comunicação entre o Front-end e o banco de dados, gerenciando as requisições e respostas necessárias para o funcionamento do sistema.\par

\noindent \href{https://nodejs.org/docs/latest/api/}{\underline{Documentação Node.js}}\par

\item \noindent Prisma:\originalspace{}\par

\noindent Utilizado como ORM para simplificar as operações de banco da dados, como consultas, inserções, atualizações e exclusões. O prisma facilitou a modelagem e integração com o banco de dados PostgreSQL de forma segura e eficiente.\par

\noindent \href{https://www.prisma.io/docs}{\underline{Documentação Prisma}}\par

\item \noindent PostgreSQL:\originalspace{}\par

\noindent Utilizado com banco de dados principal do sistema, armazenando informações dos usuários, configurações dos tablets, dados dos lojistas e administradores, suplementos e outras informações necessárias para o funcionamento do sistema.\par

\noindent \href{https://www.postgresql.org/docs/}{\underline{Documentação PostgreSQL}}\par

\end{itemize}

\noindent Essas tecnologias foram integradas de forma a proporcionar uma experiência completa para os usuários finais, permitindo a interação com o fluxograma de descoberta de suplementos no tablet, o gerenciamento dos tablets pelo lojista na plataforma web específica, e o gerenciamento global do sistema pelos administradores na plataforma web dedicada a eles.\par
