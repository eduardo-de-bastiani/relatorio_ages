\subsection{Tecnologias utilizadas}
\label{ages-i:text-h-0012}

Para o desenvolvimento do projeto, utilizamos TypeScript \cite{typescript-docs} para desenvolver as telas do tablet, utilizando componentes do React \cite{react-docs}. A tipagem estática do TypeScript proporcionou maior segurança e facilidade na manutenção do código Front-end.
Também utilizamos TypeScript para desenvolver a lógica de negócios, APIs e integrações necessárias para o funcionamento do sistema. A linguagem trouxe a mesma segurança e facilidade de manutenção para o código do servidor.

Para criar a interface do usuário no tablet, utilizamos React \cite{react-docs}, permitindo a interação com o fluxograma para descobrir os melhores suplementos.
A biblioteca também foi utilizada para criar as interfaces web acessíveis pelo lojista e pelo administrador, com layouts similares e funcionalidades específicas para cada tipo de usuário.
Já o Node.js \cite{nodejs-docs} foi utilizado para criar as APIs RESTful que permitem a comunicação entre o Front-end e o banco de dados, gerenciando as requisições e respostas necessárias para o funcionamento do sistema.

Para simplificar as operações de banco da dados, como consultas, inserções, atualizações e exclusões, utilizamos Prisma \cite{prisma-docs} como ORM. O prisma facilitou a modelagem e integração com o banco de dados PostgreSQL \cite{postgresql-docs} de forma segura e eficiente.
O PostgreSQL foi utilizado como banco de dados principal do sistema, armazenando informações dos usuários, configurações dos tablets, dados dos lojistas e administradores, suplementos e outras informações necessárias para o funcionamento do sistema.

Essas tecnologias foram integradas de forma a proporcionar uma experiência completa para os usuários finais, permitindo a interação com o fluxograma de descoberta de suplementos no tablet, o gerenciamento dos tablets pelo lojista na plataforma web específica, e o gerenciamento global do sistema pelos administradores na plataforma web dedicada a eles.\par
