\subsection{Tecnologias utilizadas}
\label{ages-i:text-h-0012}

\indent \originaltab{}Para o desenvolvimento do projeto, utilizamos as seguintes tecnologias:
TypeScript:\space\cite{typescript-docs} Utilizado para desenvolver as telas do tablet, utilizando componentes do React. A tipagem estática do TypeScript proporcionou maior segurança e facilidade na manutenção do código Front-end. Também foi utilizado para desenvolver a lógica de negócios, APIs e integrações necessárias para o funcionamento do sistema. O TypeScript trouxe a mesma segurança e facilidade de manutenção para o código do servidor. \href{https://www.typescriptlang.org/docs/}{Documentação TypeScript};
React:\space\cite{react-docs} Utilizado para criar a interface do usuário no tablet, permitindo a interação com o fluxograma para descobrir os melhores suplementos. Também foi utilizado para criar as interfaces web acessíveis pelo lojista e pelo administrador, com layouts similares e funcionalidades específicas para cada tipo de usuário. \href{https://react.dev/}{Documentação React};
Node.js:\space\cite{nodejs-docs} Utilizado para criar as APIs RESTful que permitem a comunicação entre o Front-end e o banco de dados, gerenciando as requisições e respostas necessárias para o funcionamento do sistema. \href{https://nodejs.org/docs/latest/api/}{Documentação Node.js};
Prisma:\space\cite{prisma-docs} Utilizado como ORM para simplificar as operações de banco da dados, como consultas, inserções, atualizações e exclusões. O prisma facilitou a modelagem e integração com o banco de dados PostgreSQL de forma segura e eficiente. \href{https://www.prisma.io/docs}{Documentação Prisma};
PostgreSQL:\space\cite{postgresql-docs} Utilizado com banco de dados principal do sistema, armazenando informações dos usuários, configurações dos tablets, dados dos lojistas e administradores, suplementos e outras informações necessárias para o funcionamento do sistema. \href{https://www.postgresql.org/docs/}{Documentação PostgreSQL}. Essas tecnologias foram integradas de forma a proporcionar uma experiência completa para os usuários finais, permitindo a interação com o fluxograma de descoberta de suplementos no tablet, o gerenciamento dos tablets pelo lojista na plataforma web específica, e o gerenciamento global do sistema pelos administradores na plataforma web dedicada a eles.\par
